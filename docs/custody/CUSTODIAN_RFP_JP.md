# MT5 カストディ／登録パートナー確認票

## 対象サービス

Solana Token-2022の指数連動Vault Shareと、その裏付けとなる5種類の
SPLトークンおよびUSDCの分別管理、作成・償還、残高証明。

## 必須確認事項

- 金融庁・財務局の登録番号と提供可能な業務範囲
- SOL、Token-2022、任意SPLトークン、USDCの対応可否
- 新規・非上場ミームコインを含む専用アドレス管理の可否
- 顧客資産と自己資産の分別方法
- 破綻隔離、秘密鍵管理、MPC/HSM、地理的分離、職務分掌
- Squads 2-of-3との共同運用または監視専用連携の可否
- 日次残高ファイルへの機械署名と公開アドレス開示の可否
- 入出庫承認、KYC/AML、トラベルルール、制裁スクリーニング
- インシデント通知SLA、保険、監査報告書、ペネトレーションテスト
- 作成・償還の締切、処理時間、最低金額、手数料
- 日本居住者向け提供および登録販売・媒介パートナー対応

## 最低受入条件

- 契約主体と登録範囲を法務が確認できる
- 専用Vaultまたは法的に同等な分別口座
- 24時間以内の署名済み残高報告
- オンチェーン残高との差異10bps以内
- 高・重大監査所見が未解決でない
- 緊急停止および鍵侵害時の共同手順が文書化される

登録一覧への掲載は価値保証や当該商品取扱いの承認を意味しないため、
個別に取扱可否と契約範囲を確認する。
